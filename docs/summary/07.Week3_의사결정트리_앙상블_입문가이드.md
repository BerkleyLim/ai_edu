### 1.2 Non-parametric Model (비모수 모델)이란?

**모수 모델 vs 비모수 모델**

**모수 모델 (Parametric Model)**
```
- 고정된 수의 파라미터를 가짐
- 데이터의 분포를 가정
- 예: 선형회귀 y = ax + b (파라미터 a, b 2개)
```

**비모수 모델 (Non-parametric Model)**  
```
- 파라미터 수가 데이터에 따라 변함
- 데이터 분포를 가정하지 않음
- 더 유연하지만 해석이 어려울 수 있음
- 예: 의사결정트리, k-NN
```

**비교 예시:**
```python
# 모수 모델: 선형회귀 (파라미터 2개 고정)
from sklearn.linear_model import LinearRegression
linear_model = LinearRegression()  # y = ax + b

# 비모수 모델: 의사결정트리 (데이터에 따라 노드 수 변화)
from sklearn.tree import DecisionTreeRegressor  
tree_model = DecisionTreeRegressor()  # 트리 구조가 데이터에 따라 달라짐
```

## 🌳 2. 의사결정트리 (Decision Tree) 완전 정복

### 2.1 의사결정트리란?

**직관적 설명:**
```
사람이 결정을 내리는 방식과 비슷
"만약 A라면 → B를 선택, 그렇지 않으면 → C를 선택"

예: 데이트 상대 고르기
├─ 키가 170cm 이상인가?
│  ├─ Yes → 성격이 좋은가?
│  │  ├─ Yes → 만난다 ❤️
│  │  └─ No → 안 만난다 💔
│  └─ No → 돈이 많은가?
│     ├─ Yes → 만난다 💰
│     └─ No → 안 만난다 💔
```

### 2.2 의사결정트리의 핵심 원리

#### 2.2.1 불순도 (Impurity) 개념

**불순도란?**
- 한 그룹에 서로 다른 클래스가 섞여있는 정도
- 불순도가 낮을수록 = 같은 클래스끼리 잘 모여있음 = 좋음

**지니 불순도 (Gini Impurity)**
```
Gini = 1 - Σ(pᵢ)²
pᵢ: i번째 클래스의 비율
```

**Python으로 직접 계산해보기:**
```python
def calculate_gini(labels):
    """지니 불순도 계산"""
    if len(labels) == 0:
        return 0
    
    # 각 클래스별 개수 세기
    unique, counts = np.unique(labels, return_counts=True)
    probabilities = counts / len(labels)
    
    # 지니 불순도 계산
    gini = 1 - np.sum(probabilities ** 2)
    return gini

# 예시
labels1 = ['A', 'A', 'A', 'A']  # 완전히 순수
labels2 = ['A', 'B', 'A', 'B']  # 완전히 섞임
labels3 = ['A', 'A', 'A', 'B']  # 약간 섞임

print(f"완전히 순수한 그룹의 지니: {calculate_gini(labels1):.3f}")  # 0.000
print(f"완전히 섞인 그룹의 지니: {calculate_gini(labels2):.3f}")    # 0.500  
print(f"약간 섞인 그룹의 지니: {calculate_gini(labels3):.3f}")      # 0.375
```

**엔트로피 (Entropy)**
```
Entropy = -Σ pᵢ × log₂(pᵢ)
```

```python
def calculate_entropy(labels):
    """엔트로피 계산"""
    if len(labels) == 0:
        return 0
    
    unique, counts = np.unique(labels, return_counts=True)
    probabilities = counts / len(labels)
    
    # log₂(0)을 피하기 위해 0인 확률 제거
    probabilities = probabilities[probabilities > 0]
    entropy = -np.sum(probabilities * np.log2(probabilities))
    
    return entropy

print(f"완전히 순수한 그룹의 엔트로피: {calculate_entropy(labels1):.3f}")  # 0.000
print(f"완전히 섞인 그룹의 엔트로피: {calculate_entropy(labels2):.3f}")    # 1.000
print(f"약간 섞인 그룹의 엔트로피: {calculate_entropy(labels3):.3f}")      # 0.811
```

#### 2.2.2 정보 이득 (Information Gain)

**정보 이득이란?**
- 분할 전후의 불순도 감소량
- 정보 이득이 클수록 = 좋은 분할

```
정보 이득 = 분할 전 불순도 - (분할 후 가중 평균 불순도)

IG(S, A) = Entropy(S) - Σ |Sᵥ|/|S| × Entropy(Sᵥ)
S: 전체 데이터, A: 분할 속성, Sᵥ: 분할된 부분집합
```

**Python으로 정보 이득 계산:**
```python
def information_gain(parent, left_child, right_child, metric='entropy'):
    """정보 이득 계산"""
    if metric == 'entropy':
        calc_func = calculate_entropy
    else:  # gini
        calc_func = calculate_gini
    
    # 전체 샘플 수
    total_samples = len(parent)
    
    # 분할 전 불순도
    parent_impurity = calc_func(parent)
    
    # 분할 후 가중 평균 불순도
    left_weight = len(left_child) / total_samples
    right_weight = len(right_child) / total_samples
    
    weighted_impurity = (left_weight * calc_func(left_child) + 
                        right_weight * calc_func(right_child))
    
    # 정보 이득
    gain = parent_impurity - weighted_impurity
    return gain

# 예시: 날씨에 따른 테니스 여부
parent = ['Yes', 'Yes', 'No', 'No', 'Yes', 'No']

# 맑음/흐림으로 분할
sunny = ['Yes', 'No', 'No']  
cloudy = ['Yes', 'Yes', 'No']

gain = information_gain(parent, sunny, cloudy)
print(f"날씨로 분할했을 때 정보 이득: {gain:.3f}")
```

### 2.3 의사결정트리 알고리즘 완전 구현

```python
import numpy as np
from collections import Counter
import matplotlib.pyplot as plt

class DecisionTreeFromScratch:
    def __init__(self, max_depth=5, min_samples_split=2, criterion='gini'):
        """
        의사결정트리 초기화
        
        Args:
            max_depth: 최대 깊이
            min_samples_split: 분할하기 위한 최소 샘플 수
            criterion: 분할 기준 ('gini' or 'entropy')
        """
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.criterion = criterion
        self.tree = None
    
    def _calculate_impurity(self, y):
        """불순도 계산"""
        if len(y) == 0:
            return 0
        
        counts = Counter(y)
        probabilities = np.array(list(counts.values())) / len(y)
        
        if self.criterion == 'gini':
            return 1 - np.sum(probabilities ** 2)
        elif self.criterion == 'entropy':
            # 0 log 0 = 0으로 처리
            probabilities = probabilities[probabilities > 0]
            return -np.sum(probabilities * np.log2(probabilities))
    
    def _find_best_split(self, X, y):
        """최적 분할점 찾기"""
        best_gain = -1
        best_feature = None
        best_threshold = None
        
        n_features = X.shape[1]
        parent_impurity = self._calculate_impurity(y)
        
        for feature_idx in range(n_features):
            # 해당 특성의 유니크한 값들을 임계값 후보로 사용
            thresholds = np.unique(X[:, feature_idx])
            
            for threshold in thresholds:
                # 분할
                left_mask = X[:, feature_idx] <= threshold
                right_mask = ~left_mask
                
                # 최소 샘플 수 체크
                if np.sum(left_mask) == 0 or np.sum(right_mask) == 0:
                    continue
                
                # 정보 이득 계산
                left_impurity = self._calculate_impurity(y[left_mask])
                right_impurity = self._calculate_impurity(y[right_mask])
                
                n_left, n_right = np.sum(left_mask), np.sum(right_mask)
                n_total = len(y)
                
                weighted_impurity = (n_left/n_total * left_impurity + 
                                   n_right/n_total * right_impurity)
                
                gain = parent_impurity - weighted_impurity
                
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature_idx
                    best_threshold = threshold
        
        return best_feature, best_threshold, best_gain
    
    def _build_tree(self, X, y, depth):
        """재귀적으로 트리 구축"""
        # 종료 조건들
        n_samples = len(y)
        n_classes = len(np.unique(y))
        
        # 리프 노드 조건
        if (depth >= self.max_depth or 
            n_classes == 1 or 
            n_samples < self.min_samples_split):
            
            # 가장 많은 클래스를 예측값으로
            most_common_class = Counter(y).most_common(1)[0][0]
            return {
                'prediction': most_common_class,
                'samples': n_samples,
                'impurity': self._calculate_impurity(y)
            }
        
        # 최적 분할점 찾기
        best_feature, best_threshold, best_gain = self._find_best_split(X, y)
        
        if best_feature is None:  # 더 이상 분할할 수 없음
            most_common_class = Counter(y).most_common(1)[0][0]
            return {
                'prediction': most_common_class,
                'samples': n_samples,
                'impurity': self._calculate_impurity(y)
            }
        
        # 분할
        left_mask = X[:, best_feature] <= best_threshold
        right_mask = ~left_mask
        
        # 자식 노드 생성
        left_child = self._build_tree(X[left_mask], y[left_mask], depth + 1)
        right_child = self._build_tree(X[right_mask], y[right_mask], depth + 1)
        
        return {
            'feature': best_feature,
            'threshold': best_threshold,
            'gain': best_gain,
            'samples': n_samples,
            'impurity': self._calculate_impurity(y),
            'left': left_child,
            'right': right_child
        }
    
    def fit(self, X, y):
        """트리 학습"""
        self.feature_names = [f'feature_{i}' for i in range(X.shape[1])]
        self.tree = self._build_tree(X, y, 0)
        return self
    
    def _predict_single(self, x, node):
        """단일 샘플 예측"""
        if 'prediction' in node:  # 리프 노드
            return node['prediction']
        
        if x[node['feature']] <= node['threshold']:
            return self._predict_single(x, node['left'])
        else:
            return self._predict_single(x, node['right'])
    
    def predict(self, X):
        """예측"""
        predictions = []
        for x in X:
            pred = self._predict_single(x, self.tree)
            predictions.append(pred)
        return np.array(predictions)
    
    def print_tree(self, node=None, depth=0, side="Root"):
        """트리 구조 출력"""
        if node is None:
            node = self.tree
        
        indent = "  " * depth
        
        if 'prediction' in node:  # 리프 노드
            print(f"{indent}{side}: Predict '{node['prediction']}' "
                  f"(samples: {node['samples']}, impurity: {node['impurity']:.3f})")
        else:
            print(f"{indent}{side}: {self.feature_names[node['feature']]} <= {node['threshold']:.3f}")
            print(f"{indent}  ├─ gain: {node['gain']:.3f}, samples: {node['samples']}")
            
            self.print_tree(node['left'], depth + 1, "├─ True")
            self.print_tree(node['right'], depth + 1, "└─ False")

# 실제 사용 예시
if __name__ == "__main__":
    # 간단한 데이터셋 생성
    from sklearn.datasets import make_classification
    
    X, y = make_classification(n_samples=100, n_features=4, n_classes=3, 
                              n_informative=3, n_redundant=1, random_state=42)
    
    # 트리 학습
    tree = DecisionTreeFromScratch(max_depth=3, min_samples_split=5)
    tree.fit(X, y)
    
    # 트리 구조 출력
    print("=== 학습된 의사결정트리 ===")
    tree.print_tree()
    
    # 예측
    predictions = tree.predict(X)
    accuracy = np.mean(predictions == y)
    print(f"\n훈련 정확도: {accuracy:.3f}")
```

### 2.4 의사결정트리의 장단점 이해하기

**장점 ✅**
```
1. 해석하기 쉬움 (White-box model)
2. 데이터 전처리가 거의 필요없음
3. 수치형/범주형 데이터 모두 처리 가능
4. 비선형 관계도 캐치 가능
5. 특성 중요도를 알 수 있음
```

**단점 ❌**
```
1. 과적합되기 쉬움
2. 작은 데이터 변화에 민감함 (불안정)
3. 편향될 수 있음 (특정 클래스 선호)
4. 선형 관계는 비효율적으로 학습
```

## 🎯 3. 앙상블 방법 (Ensemble Methods) 완전 정복

### 3.1 앙상블이란?

**기본 아이디어:**
```
"여러 개의 약한 학습기를 결합해서 강한 학습기를 만들자!"

예시: 
- 혼자 결정 vs 여러 전문가가 모여서 결정
- 한 사람의 의견 vs 국민투표 결과
```

**앙상블의 종류:**
```
1. 배깅 (Bagging): 병렬로 학습 → 투표
2. 부스팅 (Boosting): 순차적 학습 → 오류 보완  
3. 스태킹 (Stacking): 메타 학습기로 결합
```

### 3.2 랜덤 포레스트 (Random Forest) 완전 이해

**핵심 아이디어:**
```
1. 여러 개의 의사결정트리를 만든다
2. 각 트리는 서로 다른 데이터로 학습
3. 각 트리는 서로 다른 특성만 사용
4. 최종 결과는 투표로 결정
```

**배깅 (Bootstrap Aggregating):**
```
Bootstrap: 복원 추출로 여러 데이터셋 생성
Aggregating: 여러 모델의 결과를 합치기
```

```python
class RandomForestFromScratch:
    def __init__(self, n_trees=10, max_depth=5, max_features='sqrt', random_state=None):
        """
        랜덤 포레스트 구현
        
        Args:
            n_trees: 트리 개수
            max_depth: 각 트리의 최대 깊이
            max_features: 각 분할에서 고려할 특성 수
        """
        self.n_trees = n_trees
        self.max_depth = max_depth
        self.max_features = max_features
        self.trees = []
        self.feature_indices = []
        
        if random_state:
            np.random.seed(random_state)
    
    def _bootstrap_sample(self, X, y):
        """부트스트랩 샘플링"""
        n_samples = X.shape[0]
        indices = np.random.choice(n_samples, size=n_samples, replace=True)
        return X[indices], y[indices]
    
    def _get_feature_indices(self, n_features):
        """랜덤한 특성 선택"""
        if self.max_features == 'sqrt':
            max_features = int(np.sqrt(n_features))
        elif self.max_features == 'log2':
            max_features = int(np.log2(n_features))
        elif isinstance(self.max_features, int):
            max_features = self.max_features
        else:
            max_features = n_features
        
        return np.random.choice(n_features, size=max_features, replace=False)
    
    def fit(self, X, y):
        """랜덤 포레스트 학습"""
        self.trees = []
        self.feature_indices = []
        
        for i in range(self.n_trees):
            # 부트스트랩 샘플링
            X_bootstrap, y_bootstrap = self._bootstrap_sample(X, y)
            
            # 랜덤 특성 선택
            feature_indices = self._get_feature_indices(X.shape[1])
            X_subset = X_bootstrap[:, feature_indices]
            
            # 트리 학습
            tree = DecisionTreeFromScratch(max_depth=self.max_depth)
            tree.fit(X_subset, y_bootstrap)
            
            self.trees.append(tree)
            self.feature_indices.append(feature_indices)
        
        return self
    
    def predict(self, X):
        """예측 (다수결 투표)"""
        # 각 트리의 예측 수집
        tree_predictions = []
        
        for i, tree in enumerate(self.trees):
            feature_indices = self.feature_indices[i]
            X_subset = X[:, feature_indices]
            pred = tree.predict(X_subset)
            tree_predictions.append(pred)
        
        # 다수결 투표
        tree_predictions = np.array(tree_predictions).T  # (n_samples, n_trees)
        
        final_predictions = []
        for sample_preds in tree_predictions:
            # 가장 많이 나온 클래스 선택
            most_common = Counter(sample_preds).most_common(1)[0][0]
            final_predictions.append(most_common)
        
        return np.array(final_predictions)
    
    def predict_proba(self, X):
        """확률 예측"""
        # 각 트리의 예측 수집
        all_predictions = []
        
        for i, tree in enumerate(self.trees):
            feature_indices = self.feature_indices[i]
            X_subset = X[:, feature_indices]
            pred = tree.predict(X_subset)
            all_predictions.append(pred)
        
        all_predictions = np.array(all_predictions).T  # (n_samples, n_trees)
        
        # 클래스별 확률 계산
        unique_classes = np.unique(np.concatenate(all_predictions))
        probabilities = []
        
        for sample_preds in all_predictions:
            class_counts = Counter(sample_preds)
            sample_probs = []
            for class_label in unique_classes:
                prob = class_counts.get(class_label, 0) / self.n_trees
                sample_probs.append(prob)
            probabilities.append(sample_probs)
        
        return np.array(probabilities), unique_classes
```

### 3.3 그래디언트 부스팅 (Gradient Boosting) 원리

**부스팅의 핵심 아이디어:**
```
1. 첫 번째 모델이 예측
2. 틀린 부분을 두 번째 모델이 학습
3. 여전히 틀린 부분을 세 번째 모델이 학습
4. 이를 반복...
5. 모든 모델의 예측을 더해서 최종 결과
```

**수식으로 이해하기:**
```
F₀(x) = 초기 예측 (보통 평균값)
F₁(x) = F₀(x) + η × h₁(x)  # 첫 번째 약한 학습기 추가
F₂(x) = F₁(x) + η × h₂(x)  # 두 번째 약한 학습기 추가
...
Fₘ(x) = Fₘ₋₁(x) + η × hₘ(x)

η: 학습률 (learning rate)
hₘ(x): m번째 약한 학습기
```

```python
class SimpleGradientBoosting:
    def __init__(self, n_estimators=50, learning_rate=0.1, max_depth=3):
        """
        간단한 그래디언트 부스팅 구현 (회귀용)
        
        Args:
            n_estimators: 약한 학습기 개수
            learning_rate: 학습률
            max_depth: 각 트리의 최대 깊이
        """
        self.n_estimators = n_estimators
        self.learning_rate = learning_rate
        self.max_depth = max_depth
        self.trees = []
        self.initial_prediction = None
    
    def fit(self, X, y):
        """그래디언트 부스팅 학습"""
        # 초기 예측값 (평균)
        self.initial_prediction = np.mean(y)
        
        # 현재 예측값 초기화
        current_predictions = np.full(len(y), self.initial_prediction)
        
        for i in range(self.n_estimators):
            # 잔차 계산 (실제값 - 현재예측값)
            residuals = y - current_predictions
            
            # 잔차를 타겟으로 하는 트리 학습
            tree = DecisionTreeRegressor(max_depth=self.max_depth)
            tree.fit(X, residuals)
            
            # 트리 예측
            tree_predictions = tree.predict(X)
            
            # 현재 예측값 업데이트
            current_predictions += self.learning_rate * tree_predictions
            
            # 트리 저장
            self.trees.append(tree)
    
    def predict(self, X):
        """예측"""
        # 초기 예측값으로 시작
        predictions = np.full(X.shape[0], self.initial_prediction)
        
        # 각 트리의 예측을 순차적으로 더함
        for tree in self.trees:
            predictions += self.learning_rate * tree.predict(X)
        
        return predictions

# 간단한 회귀 트리 (DecisionTreeRegressor 대신 사용)
class DecisionTreeRegressor:
    def __init__(self, max_depth=3, min_samples_split=2):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.tree = None
    
    def _mse(self, y):
        """평균 제곱 오차"""
        if len(y) == 0:
            return 0
        return np.mean((y - np.mean(y)) ** 2)
    
    def _find_best_split_regression(self, X, y):
        """회귀를 위한 최적 분할점 찾기"""
        best_mse = float('inf')
        best_feature = None
        best_threshold = None
        
        for feature_idx in range(X.shape[1]):
            thresholds = np.unique(X[:, feature_idx])
            
            for threshold in thresholds:
                left_mask = X[:, feature_idx] <= threshold
                right_mask = ~left_mask
                
                if np.sum(left_mask) == 0 or np.sum(right_mask) == 0:
                    continue
                
                left_mse = self._mse(y[left_mask])
                right_mse = self._mse(y[right_mask])
                
                weighted_mse = (np.sum(left_mask) * left_mse + 
                               np.sum(right_mask) * right_mse) / len(y)
                
                if weighted_mse < best_mse:
                    best_mse = weighted_mse
                    best_feature = feature_idx
                    best_threshold = threshold
        
        return best_feature, best_threshold
    
    def _build_tree_regression(self, X, y, depth):
        """회귀 트리 구축"""
        # 종료 조건
        if depth >= self.max_depth or len(y) < self.min_samples_split or len(np.unique(y)) == 1:
            return {'prediction': np.mean(y)}
        
        # 최적 분할점 찾기
        best_feature, best_threshold = self._find_best_split_regression(X, y)
        
        if best_feature is None:
            return {'prediction': np.mean(y)}
        
        # 분할
        left_mask = X[:, best_feature] <= best_threshold
        right_mask = ~left_mask
        
        left_child = self._build_tree_regression(X[left_mask], y[left_mask], depth + 1)
        right_child = self._build_tree_regression(X[right_mask], y[right_mask], depth + 1)
        
        return {
            'feature': best_feature,
            'threshold': best_threshold,
            'left': left_child,
            'right': right_child
        }
    
    def fit(self, X, y):
        """트리 학습"""
        self.tree = self._build_tree_regression(X, y, 0)
        return self
    
    def _predict_single(self, x, node):
        """단일 예측"""
        if 'prediction' in node:
            return node['prediction']
        
        if x[node['feature']] <= node['threshold']:
            return self._predict_single(x, node['left'])
        else:
            return self._predict_single(x, node['right'])
    
    def predict(self, X):
        """예측"""
        predictions = []
        for x in X:
            pred = self._predict_single(x, self.tree)
            predictions.append(pred)
        return np.array(predictions)
```

```python
def regression_metrics(y_true, y_pred):
    """회귀 평가 지표들"""
    # MAE (Mean Absolute Error)
    mae = np.mean(np.abs(y_true - y_pred))
    
    # MSE (Mean Squared Error)  
    mse = np.mean((y_true - y_pred) ** 2)
    
    # RMSE (Root Mean Squared Error)
    rmse = np.sqrt(mse)
    
    # R² (결정계수)
    ss_res = np.sum((y_true - y_pred) ** 2)
    ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
    r2 = 1 - (ss_res / ss_tot)
    
    return {
        'MAE': mae,
        'MSE': mse, 
        'RMSE': rmse,
        'R²': r2
    }
```

```python
def classification_metrics(y_true, y_pred):
    """분류 평가 지표들"""
    from collections import Counter
    
    # Confusion Matrix 계산
    unique_labels = np.unique(np.concatenate([y_true, y_pred]))
    n_classes = len(unique_labels)
    
    confusion_matrix = np.zeros((n_classes, n_classes), dtype=int)
    label_to_idx = {label: idx for idx, label in enumerate(unique_labels)}
    
    for true_label, pred_label in zip(y_true, y_pred):
        true_idx = label_to_idx[true_label]
        pred_idx = label_to_idx[pred_label]
        confusion_matrix[true_idx, pred_idx] += 1
    
    # 정확도 (Accuracy)
    accuracy = np.mean(y_true == y_pred)
    
    # 클래스별 정밀도, 재현율, F1 (이진분류 예시)
    if n_classes == 2:
        tn, fp, fn, tp = confusion_matrix.ravel()
        
        precision = tp / (tp + fp) if (tp + fp) > 0 else 0
        recall = tp / (tp + fn) if (tp + fn) > 0 else 0
        f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
        
        return {
            'Accuracy': accuracy,
            'Precision': precision,
            'Recall': recall,
            'F1-Score': f1,
            'Confusion Matrix': confusion_matrix
        }
    
    return {
        'Accuracy': accuracy,
        'Confusion Matrix': confusion_matrix
    }

# 예시

        print(f"{metric}: {value:.3f}")
```

### 4.3 군집화 (Clustering) - 비지도학습

**목적**: 비슷한 데이터끼리 그룹으로 묶기 (정답 없음)
```

```

**k-평균 군집화 구현:**
```python
class KMeansFromScratch:
    def __init__(self, k=3, max_iters=100, random_state=None):
        """
        k-평균 군집화
        
        Args:
            k: 클러스터 개수
            max_iters: 최대 반복 횟수
        """
        self.k = k
        self.max_iters = max_iters
        if random_state:
            np.random.seed(random_state)
    
    def fit(self, X):
        """k-평균 학습"""
        n_samples, n_features = X.shape
        
        # 중심점 초기화 (랜덤)
        self.centroids = np.random.randn(self.k, n_features)
        
        for i in range(self.max_iters):
            # 각 점을 가장 가까운 중심점에 할당
            distances = np.sqrt(((X - self.centroids[:, np.newaxis])**2).sum(axis=2))
            labels = np.argmin(distances, axis=0)
            
            # 중심점 업데이트
            new_centroids = np.zeros((self.k, n_features))
            for j in range(self.k):
                if np.sum(labels == j) > 0:
                    new_centroids[j] = np.mean(X[labels == j], axis=0)
                else:
                    new_centroids[j] = self.centroids[j]  # 할당된 점이 없으면 그대로
            
            # 수렴 체크
            if np.allclose(self.centroids, new_centroids):
                print(f"수렴 완료: {i+1} iterations")
                break
            
            self.centroids = new_centroids
        
        self.labels = labels
        return self
    
    def predict(self, X):
        """새로운 데이터 클러스터 할당"""
        distances = np.sqrt(((X - self.centroids[:, np.newaxis])**2).sum(axis=2))
        return np.argmin(distances, axis=0)
    
    def plot_clusters(self, X):
        """2D 클러스터 시각화"""
        if X.shape[1] != 2:
            print("2D 데이터만 시각화 가능합니다.")
            return
        
        plt.figure(figsize=(10, 8))
        colors = ['red', 'blue', 'green', 'purple', 'orange']
        
        # 데이터 점들
        for i in range(self.k):
            cluster_points = X[self.labels == i]
            if len(cluster_points) > 0:
                plt.scatter(cluster_points[:, 0], cluster_points[:, 1], 
                           c=colors[i % len(colors)], label=f'Cluster {i}', alpha=0.6)
        
        # 중심점들
        plt.scatter(self.centroids[:, 0], self.centroids[:, 1], 
                   c='black', marker='x', s=200, linewidths=3, label='Centroids')
        
        plt.xlabel('Feature 1')
        plt.ylabel('Feature 2')
        plt.title('K-Means Clustering')
        plt.legend()
        plt.grid(True, alpha=0.3)
        plt.show()

# k-평균 군집화 예시
```

```python
                print(f"  재현율: {test_metrics['Recall']:.3f}")
                print(f"  F1 점수: {test_metrics['F1-Score']:.3f}")
        
        return self
    
    def analyze_features(self):
        """특성 중요도 분석"""
        feature_names = ['Pclass', 'Sex', 'Age', 'SibSp', 'Parch', 'Fare']
        
        print("\n=== 특성 중요도 분석 ===")
        
        # 의사결정트리 구조 출력
        if 'Decision Tree' in self.models:
            print("\n의사결정트리 구조:")
            tree = self.models['Decision Tree']
            tree.feature_names = feature_names
            tree.print_tree()
        
        # 간단한 특성별 생존율 분석
        print("\n=== 특성별 생존율 분석 ===")
        
        # 성별별 생존율
        male_survival = self.data[self.data['Sex'] == 0]['Survived'].mean()
        female_survival = self.data[self.data['Sex'] == 1]['Survived'].mean()
        print(f"남성 생존율: {male_survival:.3f}")
        print(f"여성 생존율: {female_survival:.3f}")
        
        # 클래스별 생존율
        for pclass in [1, 2, 3]:
            class_survival = self.data[self.data['Pclass'] == pclass]['Survived'].mean()
            print(f"{pclass}등급 생존율: {class_survival:.3f}")
        
        return self
    
    def visualize_results(self):
        """결과 시각화"""
        plt.figure(figsize=(15, 10))
        
        # 1. 모델 성능 비교
        plt.subplot(2, 3, 1)
        models = list(self.results.keys())
        train_accs = [self.results[model]['train_accuracy'] for model in models]
        test_accs = [self.results[model]['test_accuracy'] for model in models]
        
        x = np.arange(len(models))
        width = 0.35
        
        plt.bar(x - width/2, train_accs, width, label='Train', alpha=0.8)
        plt.bar(x + width/2, test_accs, width, label='Test', alpha=0.8)
        plt.xlabel('Models')
        plt.ylabel('Accuracy')
        plt.title('Model Performance Comparison')
        plt.xticks(x, models)
        plt.legend()
        plt.ylim(0, 1)
        
        # 2. 특성 분포
        plt.subplot(2, 3, 2)
        survived = self.data[self.data['Survived'] == 1]
        not_survived = self.data[self.data['Survived'] == 0]
        
        plt.hist(not_survived['Age'], bins=20, alpha=0.7, label='Not Survived', color='red')
        plt.hist(survived['Age'], bins=20, alpha=0.7, label='Survived', color='blue')
        plt.xlabel('Age')
        plt.ylabel('Count')
        plt.title('Age Distribution by Survival')
        plt.legend()
        
        # 3. 성별별 생존율
        plt.subplot(2, 3, 3)
        survival_by_sex = self.data.groupby('Sex')['Survived'].mean()
        plt.bar(['Male', 'Female'], survival_by_sex.values, color=['lightcoral', 'lightblue'])
        plt.ylabel('Survival Rate')
        plt.title('Survival Rate by Sex')
        plt.ylim(0, 1)
        
        # 4. 클래스별 생존율  
        plt.subplot(2, 3, 4)
        survival_by_class = self.data.groupby('Pclass')['Survived'].mean()
        plt.bar([f'Class {i}' for i in [1, 2, 3]], survival_by_class.values, 
                color=['gold', 'silver', 'brown'])
        plt.ylabel('Survival Rate')
        plt.title('Survival Rate by Class')
        plt.ylim(0, 1)
        
        # 5. 요금과 생존 관계
        plt.subplot(2, 3, 5)
        plt.scatter(not_survived['Fare'], not_survived['Age'], alpha=0.5, 
                   c='red', label='Not Survived')
        plt.scatter(survived['Fare'], survived['Age'], alpha=0.5, 
                   c='blue', label='Survived')
        plt.xlabel('Fare')
        plt.ylabel('Age')
        plt.title('Fare vs Age by Survival')
        plt.legend()
        
        # 6. Confusion Matrix (첫 번째 모델)
        if self.results:
            plt.subplot(2, 3, 6)
            first_model = list(self.results.keys())[0]
            cm = self.results[first_model]['metrics']['Confusion Matrix']
            
            plt.imshow(cm, interpolation='nearest', cmap=plt.cm.Blues)
            plt.title(f'Confusion Matrix ({first_model})')
            plt.colorbar()
            
            # 텍스트 추가
            for i in range(cm.shape[0]):
                for j in range(cm.shape[1]):
                    plt.text(j, i, str(cm[i, j]), ha='center', va='center')
            
            plt.xlabel('Predicted')
            plt.ylabel('Actual')
        
        plt.tight_layout()
        plt.show()
```
