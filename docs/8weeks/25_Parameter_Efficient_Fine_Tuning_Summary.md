# 25. Parameter-Efficient Fine-Tuning (PEFT) 요약

## 🎯 핵심 개념

**Parameter-Efficient Fine-Tuning (PEFT)**는 거대한 사전 훈련된 AI 모델을 효율적으로 특정 작업에 맞게 조정하는 기법입니다. 전체 모델을 다시 학습하는 대신, 소수의 파라미터만 조정하여 메모리와 계산 비용을 대폭 절약합니다.

## 🚀 주요 기법들

### 1. LoRA (Low-Rank Adaptation)
- **핵심 아이디어**: 가중치 변화량을 저차원 행렬의 곱으로 표현
- **작동 방식**: 
  - 기존 가중치는 고정
  - 작은 두 행렬 A, B만 학습 (W + AB)
  - 전체 파라미터의 0.1~1%만 학습
- **장점**: 
  - 메모리 효율적
  - 여러 작업에 대한 어댑터 쉽게 교체 가능
  - 기존 모델과 같은 추론 속도

### 2. VeRA (Vector-based Random Matrix Adaptation)
- **개선점**: LoRA보다 더 적은 파라미터 사용
- **방법**: 
  - 공유되는 랜덤 행렬 사용
  - 스케일링 벡터만 학습
  - LoRA 대비 10배 적은 파라미터
- **효과**: 극도로 효율적인 파인튜닝

### 3. DoRA (Weight-Decomposed Low-Rank Adaptation)
- **핵심**: 가중치를 크기(magnitude)와 방향(direction)으로 분해
- **공식**: W = m * (W₀ + ΔW) / ||W₀ + ΔW||
  - m: 크기 (스칼라)
  - W₀ + ΔW: 방향 (LoRA 방식)
- **장점**: 
  - Full Fine-tuning과 유사한 성능
  - LoRA보다 안정적인 학습

### 4. Bayesian LoRA
- **특징**: 불확실성을 고려한 LoRA
- **방법**: 
  - 가중치를 확률 분포로 모델링
  - 베이지안 추론 활용
  - 예측 불확실성 제공
- **응용**: 의료, 금융 등 신뢰성 중요한 분야

## 💡 왜 PEFT가 중요한가?

### 기존 방식의 문제점
- **Full Fine-tuning**: 전체 모델 재학습 → 막대한 계산 비용
- **Feature Extraction**: 특징 추출기만 사용 → 제한적 성능

### PEFT의 해결책
1. **효율성**: 1% 미만의 파라미터로 90% 이상 성능 달성
2. **실용성**: 일반 GPU로도 대형 모델 파인튜닝 가능
3. **유연성**: 작업별 어댑터 쉽게 교체
4. **저장공간**: 작업별로 MB 단위 어댑터만 저장

## 🔍 성능 비교

| 방법 | 학습 파라미터 | 성능 | 메모리 사용량 |
|------|--------------|------|---------------|
| Full Fine-tuning | 100% | 100% | 매우 높음 |
| LoRA | 0.1-1% | 95-99% | 낮음 |
| VeRA | 0.01-0.1% | 90-95% | 매우 낮음 |
| DoRA | 0.1-1% | 98-100% | 낮음 |

## 🎯 실제 응용 사례

1. **언어 모델**: ChatGPT, GPT-4 등의 도메인 특화
2. **이미지 생성**: Stable Diffusion의 스타일 학습
3. **음성 인식**: Whisper 모델의 언어별 최적화
4. **번역**: 특정 언어쌍에 대한 번역 품질 향상

## 📈 선택 가이드

- **빠른 실험**: VeRA 추천
- **안정적 성능**: DoRA 추천  
- **불확실성 중요**: Bayesian LoRA 추천
- **일반적 용도**: LoRA 추천

## 🔗 핵심 요약

PEFT는 AI 모델을 실용적으로 활용할 수 있게 해주는 핵심 기술입니다. 적은 비용으로 높은 성능을 달성하여, 누구나 대형 AI 모델을 자신의 용도에 맞게 커스터마이징할 수 있게 만들어줍니다.
